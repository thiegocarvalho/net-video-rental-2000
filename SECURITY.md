# Política de segurança

O Net Video Rental 2000 é um projeto estático que roda inteiramente no navegador, sem backend. Ainda assim, se você encontrar uma vulnerabilidade (por exemplo XSS por conteúdo de feed, vazamento de dados do `localStorage` ou problema nos serviços de terceiros usados), por favor **não abra uma issue pública**.

Envie o relato em particular através do canal oficial de **GitHub Security Advisories** na aba *Security* do repositório ou contate o mantenedor em privado. Inclua os passos para reproduzir e o navegador usado. Respondemos assim que possível e creditamos quem reportar, se desejar.

Apenas a versão mais recente da branch `main` recebe correções.
